# Выбор действий игрового персонажа

Автор: [Kri1mator](https://github.com/Kri1mator).

Программа обучает персонажа выбирать атаку, сильный удар, защиту или лечение в пошаговом бою. Используется табличное Q-обучение.

## Модель

Состояние: здоровье персонажа и противника, энергия, наличие зелья, наблюдаемое намерение противника. Победа или поражение завершает эпизод; длительность ограничена 30 ходами.

Награда: -1 за ход, +2 за единицу нанесённого урона, -3 за единицу полученного урона, -5 за недоступное действие, +40 за победу, -40 за поражение. Учитывается фактический урон.

## Запуск

Нужен Python 3.10 или новее. Само обучение использует только стандартную библиотеку.

```bash
python learning.py --episodes 20000 --seed 42
```

Для графика средней награды и статической визуализации действий:

```bash
python -m pip install -r requirements.txt
python visuals.py
```

Для рисунков нужен Arial в Windows или DejaVu Sans в Linux. Полученные данные и изображения сохраняются в results; исходники рисунков для рендера - в tmp.

## Проверка

```bash
python -m unittest discover -s tests -v
```

Девять проверок охватывают правила боя, ограничение лечения, расход энергии, терминальные переходы, обновление Q и воспроизводимость обучения.

## Результат эксперимента

Обучение: 20 000 эпизодов, seed 42, alpha 0.2, gamma 0.95. Epsilon уменьшается с 1 до 0.05 за первые 80% обучения.

| Показатель в 1000 проверочных боях | Случайная стратегия | Обученный агент |
| --- | ---: | ---: |
| Победы | 247 | 1000 |
| Средняя награда | -33.67 | 42.991 |
| Недоступные действия | 1026 | 13 |

Средняя награда первых 100/последних 100 учебных эпизодов: -32.03 / 39.86. Демонстрационный бой завершился победой за 7 ходов с наградой 37.

Результаты относятся к упрощённой модели с заранее известным намерением противника и полной блокировкой урона защитой. Они не доказывают оптимальность стратегии.

## Файлы

- learning.py - среда, Q-обучение, оценка и демонстрация.
- visuals.py - график награды и статическая схема действий.
- tests/test_learning.py - автоматические проверки.
- requirements.txt - зависимости для рисунков.
